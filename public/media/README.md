# Media Buildforge

Coloca aquí los assets promocionales de la sección `#servicios`:

| Archivo | Uso |
|---------|-----|
| `buildforge-servicios.mp4` | Video corto (15–45 s, recomendado &lt;5 MB) |
| `buildforge-servicios-poster.jpg` | Imagen poster / fallback si el video no carga |

Si los archivos no existen, la UI muestra un placeholder automáticamente.

Variables opcionales: `NEXT_PUBLIC_SERVICES_VIDEO_URL`, `NEXT_PUBLIC_SERVICES_POSTER_URL`.
